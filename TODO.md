# Roadmap

Each task here is a choice of the owner. A task leaves this list when its
release is out. The reason for each choice is in
[docs/decisions.md](docs/decisions.md).

Each release adds one large function. Read the same function in Asabunko
before you write it here.

## Releases

- 0.1.0 The library and the comic archives, with the comic reader, the
  three looks with E-ink, the volume keys, and the updates inside the app.
- 0.2.0 EPUB, TXT, FB2, and HTML novels, with the reader of novels.
- 0.3.0 PDF.
- 0.4.0 MOBI and AZW3 books with no DRM.
- 0.5.0 The folders of the device, which the app watches.
- 0.6.0 The source list and the OPDS catalogs.
- 0.7.0 Mihon extensions on the device.
- 0.8.0 The Cloudflare challenge in a web view, for each source.
- 0.9.0 The Kotatsu parsers as a plugin.
- 0.10.0 LNReader plugins.
- 0.11.0 Suwayomi servers.
- 0.12.0 Aidoku sources, with the canvas and js imports.
- 0.13.0 Paperback 0.9 extensions, with executeInWebView.
- 0.14.0 Chapter downloads in the background.
- 1.0.0 All of these functions, with the backup of Asabunko, the import of a
  Mihon backup, and the check for new chapters.

## Open points

- The full roadmap of Asabunko comes to iOS now. Study each function there
  when it is out, and do not design it again here: the filters and the
  settings of the sources, and the Cloudflare web view.
- The owner makes the signing key before the release of 0.1.0.
